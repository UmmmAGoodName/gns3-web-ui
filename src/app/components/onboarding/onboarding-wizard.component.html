Welcome to GNS3!

GNS3 is a powerful network simulation platform that lets you design, build, and test complex network topologies using real device images and virtual machines.

This short wizard will walk you through the key concepts to get up and running. You can skip any step or come back later.

dns

Configure Compute Servers

GNS3 uses compute servers to run your network devices. By default, your local machine acts as the compute. You can also add remote compute servers to distribute the processing load across multiple hosts.

Navigate to Management → Computes to view and add compute nodes.

inventory_2

Install Appliances & Images

Appliances are pre-configured device definitions (routers, switches, firewalls, etc.). To use them you'll need the corresponding disk images — these are usually vendor-provided QEMU, IOS, or Docker images.

Use the Image Manager to upload and manage your images, then install appliances from the GNS3 marketplace or import your own .gns3a file.

Install Templates

Templates are reusable device configurations that appear in your device palette when building a topology. Each template is linked to a specific image and compute.

Go to Management → Templates to see installed templates, or use File → Add a template inside a project to install a new appliance from the GNS3 marketplace.

Create Your First Project

Everything in GNS3 lives inside a project. A project holds your network topology, device configurations, and saved state.

Click Projects in the navigation to see your existing projects or create a new one using the + New Project button.

Opening Device Consoles

Once your topology is running, you can access device consoles to configure them. Simply right-click a node in the canvas and select Console (or Auxiliary Console).

GNS3 supports multiple console types depending on the device:

  • Telnet — for routers, switches, and most VMs
  • VNC — for graphical desktop VMs
  • SPICE — for QEMU VMs with enhanced graphics
  • HTTP/HTTPS — for web-managed devices

You can also open all consoles at once via Tools → Console → Open all consoles.
